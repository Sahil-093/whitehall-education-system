# Whitehall Education System

School register for Whitehall Education System, Karak, Khyber Pakhtunkhwa.

Attendance, fees, staff, and results stay in the browser on the computer that opens the site. Those records are not stored in this repository.

New admissions are written to the Whitehall admission sheet on sahilktk093@gmail.com. School papers live in the Drive folder.

- Admission sheet: https://docs.google.com/spreadsheets/d/1xEAQ2b9bTNcKBEYVziacZ48cuXlMMcl0SuLMNvnMm5I/edit?gid=966990833#gid=966990833
- Drive folder: https://drive.google.com/drive/folders/1MqhtgWR04gmvcxbko_sv0Z0aYOJMR8R3?usp=sharing
- Results sheet: https://docs.google.com/spreadsheets/d/186arjbjEuHz7dqO5TrVBG1lWOW0pxGbWeZV1c_rqLqE/edit?gid=153841978#gid=153841978
