# Whitehall Education System

School register for Whitehall Education System, Karak, Khyber Pakhtunkhwa.

Admissions, attendance, fees, staff, and results stay in the browser on the computer that opens the site. Student records are not stored in this repository.

## Site

https://sahil-093.github.io/whitehall-education-system/

## Local preview

```bash
npm install
npm run dev
```

Open http://localhost:3000.
